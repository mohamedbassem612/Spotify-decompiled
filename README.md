# Spotify Android 9.2.0.26 — decompiled reference

This repository contains JADX output for Spotify Android package `com.spotify.music`, version `9.2.0.26` (version code `148373686`). The source tree is organized under `sources/`; decoded resources are under `resources/`.

This is a decompiled reference project. It is useful for reading and editing the generated Java and resource files, but it is not the original Android Studio project and does not include the original Gradle files or signing material. Decompiler output can be incomplete or incorrect; obfuscated names are retained.

## Contents

- `sources/` — generated Java source, grouped by package.
- `resources/` — decoded Android resources from the base APK.
- `analysis/REPORT.md` — tool versions, coverage and per DEX diagnostics.
- `analysis/evidence/` — REA package, signature and selected method evidence.
- `analysis/jadx-logs/` — individual DEX decompiler logs.
- `tools/ExportJadx.java` — small Java API driver used to export individual DEX files.

## Editing

Open `sources/` in a code editor and search by package or class name. Most release classes are obfuscated. Decompiled Java is not guaranteed to compile; use the DEX file and analysis evidence as the source of truth when generated Java is ambiguous.

The original APK/APKM files are intentionally not stored here. `analysis/evidence/` records their SHA-256 digests and the analysis selectors.
